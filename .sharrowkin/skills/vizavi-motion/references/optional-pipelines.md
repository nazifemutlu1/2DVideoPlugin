# Optional-модули: изображения, 3D, UI, референсы и провайдеры

Эти модули не являются частью штатного 2DVideoPlugin и не должны включаться по умолчанию. Они полезны только по явной задаче и только если пользователь разрешил соответствующий маршрут. Главный ролик не должен блокироваться из-за отсутствия optional-возможности.

## Общий статус

| Модуль | Статус в 2DVideoPlugin | Правило |
|---|---|---|
| Изображения/PNG с alpha | Нет документированного image/sprite pipeline | Не обещать; только отдельная инженерная задача |
| Готовые 3D-модели GLB/glTF | Нет GLTFLoader | Не обещать; только процедурные примитивы |
| Внешние image/3D-провайдеры | Не интегрированы | Не вызывать, не регистрировать аккаунты, не устанавливать MCP |
| SaaS/UI motion | Реализуем кодом 2D/2.5D; 3D UI — вручную | Можно, но в пределах engine API |
| Видео-референсы | Разбор возможен вручную | Смотреть фактический материал, не угадывать |
| Стили/источники | Пять пресетов + custom `styles.js` | Не выдавать demo-стили за универсальные |
| Beat detection | Нет | Синхронизация вручную, проверка слухом |

Если задача требует нового пакета, MCP, API-ключа, аккаунта, скачивания модели или ассетного загрузчика — остановись и запроси отдельное разрешение. Не добавляй зависимости в `package.json` и не меняй engine ради optional-модуля.

## 1. Изображения и alpha

- В документированном API нет функции вставки изображения/спрайта. Dev-server может отдавать `.png/.jpg/.svg`, но это не значит, что сцена умеет их рисовать.
- Собственный асинхронный загрузчик можно обсуждать только как отдельную задачу с проверкой детерминизма, предзагрузки, CORS/путей и рендера. Это не штатный и не проверенный путь.
- Если пользователь даёт готовые изображения, не обещай их автоматическое использование. Предложи либо перерисовать ключевые элементы кодом, либо отдельный технический проход с явным согласованием.
- Для прозрачности нужен настоящий PNG alpha; нарисованная шахматка или однотонный фон не являются прозрачностью. Проверяй край на тёмной и светлой подложке, цветной ореол и premultiplied alpha.
- Для серии поз одного героя используй один канонический reference, а не цепочку дрейфующих перегенераций. Три позы — дискретная серия, не плавное вращение.
- Crop/zoom/параллакс одного изображения не равен новой позе или свободной 3D-камере. Не обещай ракурс, которого нет в исходнике.

## 2. Условные image-провайдеры

Исходное исследование Vizavi датировано 16.10.2026 и не является интеграцией или гарантией доступа. Не считай его разрешением на регистрацию, оплату или установку.

| Маршрут | Что важно помнить |
|---|---|
| Krea MCP | MCP/OAuth и API-token могут расходовать разные балансы; free units не гарантируют число reference edits; native alpha не подтверждён |
| Cloudflare Workers AI | REST-кандидат, не готовый универсальный MCP; схема FLUX.2 Klein ограничивает reference-изображения и требует отдельного адаптера |
| Gemini web / ChatGPT Images | Веб-резервы, не бесплатный API; наличие браузера и скачивания нужно проверять фактически |
| Leonardo / Ideogram / Hugging Face / Pollinations / Recraft | Free-планы ограничены, условия и права различаются; API не обещать |
| Replicate / fal | Trial не равен постоянному free-маршруту; проверяй конкретное предложение |
| ComfyUI + rembg | Локальный маршрут только при уже доступном окружении и явном разрешении; не устанавливать автоматически; VRAM может не хватить |

Даже если изображение получено, его нельзя автоматически вставить в сцену: см. ограничение выше. Любой итоговый ассет требует проверки прав, alpha, края и фактического появления в рендере.

## 3. 3D-модели и источники

Штатный путь — процедурные примитивы Three.js. Готовые GLB/glTF сейчас не загружаются.

Если в будущем появится поддержка моделей, требования такие:

- проверь точный файл, а не превью страницы: mesh, UV, текстуры, материалы, rig/анимации, внешние зависимости;
- нормализуй единицы, оси, origin/pivot, ориентацию;
- проверь нормали, топологию, толщину, alpha, roughness/metalness, color space;
- проверь текстуры после загрузки и соответствие renderer;
- настрой свет, тени, контакт и масштаб;
- для шарнирных объектов (ноутбук) вращай крышку вокруг реальной оси, а не весь корпус;
- не обещай качество, которого нет в ассете.

Условные источники из оригинала:

| Источник | Оговорка |
|---|---|
| Poly Haven Models | glTF, CC0; проверь комплект текстур |
| Kenney Assets | выбирай именно 3D-набор; GLB, CC0 |
| Quaternius | лицензия конкретного выпуска; QAL может запрещать распространение ассетов; не весь сайт CC0 |
| ambientCG | CC0; не каждый объект в GLB |
| Sketchfab | нужен аккаунт для скачивания; условия конкретной модели |
| CGTrader | проверяй реальную бесплатность и glTF-фильтр |
| KayKit Adventurers | бесплатная часть ограничена; extras платные |
| Khronos glTF Sample Assets | лицензия каждого ассета отдельно |
| Poly Pizza | автоматизированные загрузки ограничены; не основной автоматический источник |

Правила: не скачивай автоматически, не создавай аккаунт без разрешения, сохраняй источник/автора/версию/лицензию, не включай чужие ассеты в распространяемый skill-пакет.

## 4. SaaS/UI motion

Это постановка интерфейса, а не требование бизнес-модели SaaS.

### Действие

- Один правдоподобный интерфейс с последовательными данными и состояниями.
- Курсор ведёт причинное действие: hover → pressed/grab → change → result.
- Для drag фиксируй точку захвата и относительное смещение; при drop объект встраивается в слот, соседи реагируют после события.
- Показывай processing до success; не выдавай сокращённое ожидание за реальную скорость продукта.
- Демо-данные не называй реальными метриками сервиса.

### 2D / 2.5D / 3D

| Режим | Что действительно меняется |
|---|---|
| 2D UI | Плоские панели, карточки, кнопки; смысл в курсоре и смене состояний |
| 2.5D UI | Те же плоские панели разнесены по depth; камера раскрывает перекрытия и параллакс; без настоящей толщины |
| 3D UI | Реальная геометрия, кромки, боковые поверхности, свет и тени; только если реально собрано в Three.js |

Не имитируй 3D-толщину drop shadow и масштабом. Не растягивай весь UI вместе с текстом при morph: меняй реальную раскладку/размеры формы.

### Координаты и детерминизм

- Разделяй world-space UI и screen-space overlay.
- Для world-space объекта считай экранную проекцию якоря с учётом камеры, aspect и viewport.
- Курсор, захват, состояния и задержки веди одним управляемым таймлайном; не завись от реальных mouse events.
- Позиция и оформление screen-space labels не должны случайно следовать за камерой.
- Не обещай функциональный QA интерактивного приложения, если делаешь только видеодемо.

### Проверка

Смотри в темпе и на стыках: понятность действия, точность захвата, завершение drop, синхронность прогресса, идентичность интерфейса между сценами, читаемость overlay, проекцию при движении и перемотке. Наличие `translateZ` или extrusion в коде не доказывает визуальный результат.

## 5. Видео-референсы

- Если дан файл — работай с реальными кадрами и доступным аудио. Если URL — фактически открой страницу.
- Не описывай монтаж, движение или музыку по заголовку/ссылке.
- Составь карту сцен и переходов: таймкоды, границы, крупности, слои, действие, типографика, камера, свет, звук.
- Для важных стыков извлеки плотную последовательность до/внутри/после.
- Разделяй наблюдение и перенос: **видно/слышно → принцип → собственное решение**.
- Если доступен только still или текст, честно скажи об этом.
- Разбор чужого приёма не даёт прав на чужое видео, модель, шрифт или музыку.

## 6. Стили и источники

- Пять штатных пресетов: `dusk`, `midnight`, `golden`, `neon`, `storybook`.
- Custom — через `STYLES` в `engine/styles.js`: moods overrides + grade (lift/gamma/gain, sat, contrast, vignette, grain, bloom) + UI-цвета.
- Сцены должны брать цвета из `mood()`/`S()`, иначе стиль не переключится.
- Шесть demo-стилей Vizavi (карандаш, бумага, пиксель, 2D/2.5D/3D SaaS) — исторический выбор конкретного демо, не универсальный шаблон. Для нового брифа выбирай язык заново.
- В реестр источников добавляй только проверенное: точная страница, что доступно, аккаунт, условия, формат, дата проверки, ограничения. Различай текст страницы, превью, доступ к скачиванию и проверенный файл.

## 7. Правило отказа

Если optional-модуль требует:

- новой зависимости;
- внешнего аккаунта/API-ключа;
- скачивания ассета;
- собственного загрузчика;
- изменения engine/render;

— не делай это автоматически. Сообщи, что именно нужно, и продолжи основной ролик без этого модуля, если пользователь не разрешил отдельный проход.
