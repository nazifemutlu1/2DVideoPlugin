# STYLE_STUDIO3D — approved reference look

Дата фиксации: 2026-11-08. Источник: 20-секундный 3D-шот проекта
`2d-video/projects/security_3shots` (s003, Three.js, всё процедурное).

Это **визуальный язык**, а не привязка к конкретной истории. Его используем
для всех новых проектов, пока пользователь явно не выберет другой стиль.

## Название

`studio3d` — **Studio 3D / Neon Blueprint**.

## Палитра

| Роль | Цвет |
|---|---|
| Фон / void | `#050a14`, `#0c1930`, `#242b46` |
| Основной холодный свет | `#b9e6ff` |
| Teal accent / rim | `#8fffe0` |
| Amber practical | `#ffbf7a` |
| Violet accent | `#b8a5ff` |
| Text / UI | `#b9d8e8`, `#dceaff` |
| Ошибка / warning | `#ff6f61` |

## Свет

- низкий ambient, тёмный пол;
- холодный key light сверху/сзади;
- тёплые/янтарные practicals как единственные яркие пятна;
- fog `[16, 55]` — глубина важнее деталей;
- bloom сильный, но без пересвета;
- light shafts — только акцент, не на весь кадр.

## Геометрия

- low-poly procedural primitives;
- здания — box, крыши/антенны — cyl/cone;
- окна — emissive canvas textures;
- деревья — cone/sphere;
- никаких GLTF, PNG-ассетов и внешних моделей;
- масштаб: человек ~1.7 m, город — 10–30 m, маяк — 8–15 m.

## Камера

- orbit вокруг смыслового центра;
- radius 13 → 10, height 6.5 → 3.8 на 20 s;
- fov 38 → 34;
- target на уровне 3.5 m;
- движение непрерывное, без резких телепортов;
- финальный кадр читаемый, без бессмысленного вращения.

## 2D / 2.5D / 3D

- **2D** — графика, иконки, интимные сцены, текст;
- **2.5D** — слои, панели, параллакс, переходы;
- **3D** — кульминация, пространство, масштаб, корабль/город/маяк;
- переходы: `cut` внутри 2D, `fade`/`whip` между мирами;
- 3D не должно быть «демо ради демо»: только там, где нужен объём.

## UI / графика

- карточки `rgba(7,15,24,.72)`, тонкая teal-линия;
- крупные цифры/лейблы — `Nunito` 800–900;
- blueprint-линии `#7bdcff`;
- без мелкого текста и без «стены текста».

## Движение

- камера и свет ведут взгляд;
- объекты имеют вход/контакт/реакцию/затухание;
- частицы — атмосфера, не замена действию;
- не более 1–2 акцентов в кадре одновременно.
